Import existing leads from a tab

Reads the leads already sitting in a salesperson's tab so they take part in duplicate matching. Rows stay where they are and keep their owner — this adds the automation's columns alongside what is already there.

Names, emails and phone numbers are never rewritten — they stay exactly as they were typed. Matching happens on tidied copies kept out of the sheet. The one value that can change is Event Date, and only where it reads one way (03/15/2027 → 2027-03-15), with the original kept in Event Date (Raw). Every other column is filled only where it is empty, and no row is moved or deleted.
